# Power-BI---Brandlo-Mobile-Brands-Analytics-Dashboard
 Project Showcase: "Brandlo" — Mobile Brands Analytics Dashboard (Power BI)

Excited to share my latest Power BI project — an interactive dashboard analyzing mobile phone specifications across 19 major global brands including Apple, Samsung, Google, Xiaomi, OnePlus, Huawei, Nokia, Sony, and more! 📱📊

🔍 What's inside:

 ✅ Dedicated, brand-themed dashboard pages for each manufacturer

 ✅ Dynamic filters — Launched Year, Processor, and Model Name

 ✅ Key metrics: Avg. Battery Capacity, Avg. Launch Price, and Avg. Screen Size

 ✅ RAM distribution and Front/Back Camera breakdowns via bar charts & pie charts

 ✅ Fully interactive slicers for cross-filtering and drill-down analysis

🎯 Skills applied:

 Power Query (data cleaning & transformation) | DAX measures | Interactive visuals & slicers | UI/UX design for dashboards | Data storytelling

This project helped me strengthen my end-to-end BI workflow — from raw data to a polished, business-ready analytical tool.
